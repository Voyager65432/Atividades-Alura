Resumo: os três espaços de uma caixa

margin

Espaçamento externo, entre o elemento e os vizinhos. Ex.: margin: 0 auto;

padding

Espaçamento interno, entre a borda e o conteúdo. Ex.: padding: 16px;

border

O limite visual do elemento. Ex.: border: 5px solid #cf1010;

Errar o nome do arquivo da imagem é ótimo para testar o atributo alt. Todo bug é uma chance de aprender.
